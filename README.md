# Office Hours launcher

Public launcher page for ECC Seattle's Office Hours app. It gives phones a home-screen icon and forwards to the app (staff sign in with their church Google account). No data lives here.

- `https://evangelical-chinese-church-of-seattle.github.io/officehours/` opens the app.
- Add `#install` to the address for the add-to-home-screen steps.

Source of truth: `launcher/` in the private office-hours repo.
